# 玩家输入与连招图读法

[[03配置/玩家攻击/阅读入口|玩家攻击阅读入口]] · [[03配置/玩家攻击/字段中文说明|字段中文说明]]

L、H 在本库分别表示轻击、重击动作输入，不代表某个固定键盘键／手柄键；自定义键位无需改变图的连接。方向词先按内部输入类型翻译，Alt与普通同键共用≤0.2秒短按松键，互为输入栈兄弟，不能当额外轻重组合；具体方向参照和运行期选择仍保留边界。

| 原始转换类型 | 图中标记 | 中文说明 |
|---|---|---|
| Light | L | 轻击 |
| LightHold | 按住L | 长按轻击 |
| LightAlt | L-Alt | 轻击短按松开变体（≤0.2秒；与普通输入同手势，受输入栈限制） |
| LightFront | 前向+L | 前向轻击输入类型 |
| LightFrontFront | 前前+L | 双前向轻击输入类型 |
| LightBackFront | 后前+L | 后前轻击输入类型 |
| Heavy | H | 重击 |
| HeavyHold | 按住H | 长按重击 |
| HeavyAlt | H-Alt | 重击短按松开变体（≤0.2秒；与普通输入同手势，受输入栈限制） |
| HeavyFront | 前向+H | 前向重击输入类型 |
| HeavyFrontFront | 前前+H | 双前向重击输入类型 |
| HeavyBackFront | 后前+H | 后前重击输入类型 |
| AttackKnockdown | 倒地攻击 | 倒地攻击输入类型 |
| AttackKnockdownHold | 按住倒地攻击 | 长按倒地攻击输入类型 |
| Grab | 抓取 | 抓取输入类型 |
| LightRushAttack | 突进+L | 轻击突进输入类型 |

## 图例与范围

| 图中内容 | 含义／限制 |
|---|---|
| 实线箭头 | 资产中保存了对应输入和目标节点；仍需动作许可、技能和运行时条件 |
| 虚线默认入口 | GetDefaultAttackID 按输入枚举取默认攻击；不是任意状态都能立即执行 |
| 虚线重定向 | 节点保存了重定向目标；被忽略输入和动作层等规则仍影响使用 |
| 条件分支键 | 来自 Byte→节点编号映射，保留0、1、2等原始键；不能一律翻译为是／否 |
| 几率字段 | 保存的选择概率参数，不当作已经实测的频率 |
| 姿态槽0～3 | 0前左、1前右、2后右、3后左；按身体／骨盆相对目标选槽，镜像交换左右；不是四次命中 |
| 所需技能标签 | 保存的标签要求会限制节点资格；不能省略成人人可接 |
| 条件攻击覆写 | 仍有未解码项；节点基本动作并非保证是最终所选动作 |
| 图中生命／架势配置 | 标注基本动作各命中段的保存值集合，不求和，不是最终伤害或同一输入的累计值 |
| 连续命中保证 | 连招树只证明配置衔接，不证明敌人在整串期间无法格挡、闪避或恢复 |
| 长按默认回退 | GetDefaultAttackID 的 LightHold／HeavyHold 若保存-1，会分别回退到 Light／Heavy 默认节点 |

默认入口索引与转换枚举的关系已核对本机代码；证据见 inventory/player-combo-default-input-disassembly.json。目标映射类型见 inventory/player-combo-type-layouts.json，原始映射的完整消费与节点边界检查见 inventory/player-combo-graphs.json。
