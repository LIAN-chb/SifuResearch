# 复盘-0002：用本地化与UI引用核实招式名称

- 日期／性质：2026-10-29，当批复盘；可复用候选，仅本项目验证。
- 关联：ADR-0005、名称查询12，输入包及哈希见12/extraction-manifest.json。
- 目标：区分正式中文名、资源变量与整套连招标题，只查询不填图。

先查官网，能确认英文名但无完整官方简中表，没有把攻略译名升级为官方。包索引定位en/zh-Hans Game.locres及locmeta，定向提取3文件共388017字节，不复制31GB包。LocRes v3有界读取后按namespace/key/source hash配对。假设两语言集合相同失败，实际英文独有42项，改用一致源hash交集，保留未本地化的action标记。

复用已提取技能资产，按SkillUIData的Name/Description/Inputs字段SHA及export边界读取FText，形成同一对象的正式名、说明和输入证据。追亡逐北的Inputs明确AttackHeavy和被推击对手，比只看ChasingTripKick资源名可靠。52菜单命名项有43个去重中文名，不能当43个运行期动作；整套连招和替换招式分开记录。

不充分的方法：第三方攻略当官方、变量名自译、假设语言键集合相同、只看菜单key就推手势。前两项未用于确认；其余检查与修正见底稿。壁钟／人工成本未计时，不估造效率提升；新增提取字节如上，旧技能包仅读取。

复用要求：包索引可查、官方文本格式可读，至少一个UI对象指向确切文字键。缺本地文件可换可读游戏菜单画面或官方资料，另记版本。读取器仅支持观察到的LocRes v1-v3和FText Base0/StringTable11，未在别的游戏验证，不宣称通用兼容。
