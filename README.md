# SifuResearch · 《师父》解包与机制研究知识库

从《师父》（SIFU）当前版本的**游戏资产、配置、匹配符号与静态代码**中，逐步还原战斗与 AI 机制，整理为一份可定位、可复查的中文知识库，并附两个可直接打开的交互工具。

> 原游戏文件与本机存档保持只读，仓库只包含研究过程中产生的文档、脚本与导出数据。

## 🎮 交互成品（可直接打开）

两个成品都是**自包含单文件 HTML**：下载后双击即可在浏览器中使用（`file://` 可用，无需服务器）。

| 成品 | 说明 | 文件位置 |
|---|---|---|
| 🥊 **徒手招式图** | 玩家徒手全部招式的流式关系图：招式衔接、输入指令、命中段与伤害详情，可点击节点查看逐招证据 | [`Sifu/03配置/玩家攻击/招式板/徒手招式板.html`](Sifu/03配置/玩家攻击/招式板/徒手招式板.html) |
| 🎛️ **连招筛选工具** | 以全量 57 节点 / 350 边的连招图为基础，逐段模拟敌人状态（眩晕预算、防御记忆、倒地/推击约束、闪避窗口），生成连招并判定 **可复现 / 需条件 / 不可复现** | [`exports/20261119-连招编排-03/连招编排器.html`](exports/20261119-连招编排-03/连招编排器.html) |

连招工具的更细说明（生成与判定规则、交互方式）见其所在目录的 `build/` 与批次记录。

## 🔬 项目现状

- 以**静态取证**推进：从本机游戏构建的资产、配置、PDB 符号与静态代码还原战斗与 AI 机制。
- **完整源码恢复、完整 AI 算法重构与实战数值验证尚未完成**；文档中未知接口保留为明确缺口。
- 机制事实与对设计意图的推断分开标注，证据等级见 [术语与证据说明](Sifu/00索引/术语与证据说明.md)。

## 📁 目录结构

| 目录 | 内容 |
|---|---|
| `Sifu/` | 知识库主体（00索引、01机制、02实现、03配置、04方法论） |
| `exports/` | 面向研究主题的导出数据（CSV/JSON）与交互工具成品 |
| `scripts/` | 可重复执行的本地只读分析脚本 |
| `notes/` | 研究报告、工作流、批次交接与规则记录 |
| `adr/` | 决策记录（用户决定、选择理由与历史关系） |
| `inventory/` | 版本标识、清单、哈希与解析中间结果 |
| `tools/` | 已审阅的外部工具与源码信息 |
