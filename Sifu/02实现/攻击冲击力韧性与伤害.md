# 攻击冲击力韧性与伤害：简要实现

[[00索引/首页|返回首页]] · [[00索引/术语与证据说明|术语与证据]] · [[01机制/攻击冲击力韧性与伤害|阅读机制]]

本页保留理解机制所需的数据与执行入口，详细反汇编和偏移留在研究底稿。静态核对不等于实战验证。

对应：[[01机制/攻击冲击力韧性与伤害|机制说明]]。

攻击通过 AttackDB、HitBox 数据行等引用取得参数。`HitImpact` 分开保存生命伤害、Structure 伤害、SuperDizzy、硬直帧、击退距离和停顿帧；命中、防御、弹开各有结果分支，并保留相应启用开关。

此外还存在两类不同入口：

- `Resilience` 与攻击强度的比较，涉及是否形成韧性抵抗结果。
- `Resistance` 矩阵按受击者状态和攻击属性决定倒地、推退、眩晕等反应。

不能把 Structure、Resilience、Resistance 三者当成同一条数值。

`FResilienceOrderServiceInstance::OnStart/OnStop` 在防御组件的当前韧性上加减同一配置量；PDB 已确认配置名为 `UResilienceOrderService.m_iBonus`。这两处没有改写另一个独立的攻击附加韧性字段。本批已定位膝击与旋踢的服务引用、CDO与通知区间，见下方补充。

`GenerateImpact` 使用 HitBox 的韧性覆盖值；未启用覆盖时使用攻击强度枚举（Light=0、Medium=1、Strong=2）。当前韧性严格大于该值且非已破防时，进入设置韧性抵抗标志的分支。平局不满足“严格大于”；后续特殊状态分支仍可改变结果。

`ApplyImpact` 在该标志为真、非致命、未破防的分支中，处理架势影响、受击回调及条件性动画震动，绕过后面的正常 Hitted 订单与受控状态订单路径。这是抗打断解释的实际应用证据；不能据此宣称完全免疫。

硬直参数不能反推为零：计算端已先将命中配置的受击帧数乘 1/60，之后还有修正。主角样本为 `MainChar_HitBoxData / Jab_HB01` 与 `MainChar_Bats_HitBoxData / Heavy01_HB01`；普通命中生命／架势伤害分别为 10／12、20／36，受击帧为 8、24，韧性覆盖为 1、5。`ApplyDamagesMultipliers` 还处理徒手／武器伤害倍率，因此这些是配置值。

定位见研究目录 `notes/resilience-damage.md`、`inventory/action-resilience-type-layouts.json`、`inventory/resilience-damage-disassembly.json` 与 `inventory/impact-resilience-application-disassembly.json`。

## 动作韧性与应用顺序

| 步骤 | 逻辑 | 已核对的限制 |
|---|---|---|
| 服务开始 | 当前 m_iResilience += m_iBonus | 不改独立的 m_iResilienceAttackBonus |
| 服务停止 | 当前 m_iResilience -= 同一 m_iBonus | 不是保存基线后整体重置；并发／异常生命周期未穷尽 |
| 选择比较值 | 启用覆盖则用 m_iOverrideResilienceValue，否则用 m_eAttackPower | Light=0、Medium=1、Strong=2；覆盖值可超过三级枚举 |
| 标志计算 | 当前韧性严格大于比较值、非已破防时进入设置分支 | 平局不满足；特殊状态等后续分支可能改变结果 |
| 结果应用 | 韧性标志为真、非致命、未破防时走专门分支 | 跳过正常受击／受控状态订单；不代表免伤或完全不受影响 |
| 具体动作挂载 | 旧批次未检出，本批已补膝击+4／旋踢+2及通知区间 | 见C07；实际运行与当前韧性仍待核 |

## 普通硬直参数需要怎样读

| 项目 | 静态结果 | 不能据此推出 |
|---|---|---|
| 受击帧基础换算 | 配置帧数乘 1/60 写入硬直结果 | 屏幕帧率决定该参数秒数 |
| 样本 8／24 帧 | 这一步约为 0.133／0.400 秒 | 最终不可行动时间恰好相同 |
| 韧性分支跳转 | 跳过后续部分计算 | m_fStunTime 被清零 |
| 抗打断的直接证据 | ApplyImpact 绕过普通受击订单 | 仅凭硬直数值就能判断动作是否被打断 |
| 生命伤害倍率 | ApplyDamagesMultipliers 处理徒手／武器属性等 | 两个已读倍率就是完整公式 |

## 特殊反应选择

| 数据／入口 | 已核对内容 | 缺口 |
|---|---|---|
| GetAttackPropertyLevel | 当前状态匹配时可取状态专属攻击属性，否则取默认值 | 每项攻击实际使用哪个分支 |
| ComputeImpactType | 比较攻击属性与当前状态抗性，选择倒地／推退／眩晕等 | 完整实战映射 |
| 已眩晕再命中 | 普通眩晕叠加标记和特殊眩晕可用性参与分支 | 各招式最终刷新方式 |
| 持续时间保留 | 既有状态、剩余时间及配置可影响结果 | 最终追击时间不能直接从单字段读出 |
