## 术语对照

| 本库用语 | 内部名称或范围 | 当前如何理解 | 需要区分 |
|---|---|---|---|
| 普通受击硬直 | stun；OrderHitted 的计时与状态 | 一次普通受击带来的行动限制及恢复过程 | 持续眩晕、动画全长 |
| 持续受控状态 | FightingState 中的眩晕、倒地等 | 可有持续时间、累计伤害和命中限制 | 不统一称为普通硬直 |
| 眩晕 | Dizzy；特殊子状态另行区分 | 特殊反应及相应持续状态 | 普通受击与 SuperDizzy |
| 韧性 | Resilience | 与攻击采用的强度值比较，可形成抵抗命中结果 | 未证实为每次攻击累计扣除的槽 |
| 反应抗性 | Resistance | 按当前状态参与倒地、推退、眩晕等判定的数据 | 与 Resilience、Structure 分开 |
| 架势 | Structure | 架势伤害、破防等相关通道 | 不是普通硬直时长 |
| 冲击／攻击效果 | Impact 及相关攻击数据 | 多项结果的统称，须拆开具体字段 | 不是一个统一数值 |
| 格挡 | Guard | 一类防御结果／动作 | Deflect 与 Parry |
| 弹开／Deflect | EGuardType::Deflect 等明确内部结果 | 按已定位的执行路径使用名称 | 玩家口语“防反”尚不能处处一一对应 |
| 招架／防反 | 玩家用语与 Parry 相关数据 | 按场景注明玩家行为或内部标识 | 不假定所有同名事件共用机制 |
| 闪避 | Dodge／Avoid 等不同内部入口 | 保留原名以免误合并 | 闪避成功不等于闪避后反击命中 |
| 脱离 | 用户关注的现象 | 从连续受击中恢复、开始防御或反击 | 目前没有确认单一全局“脱离系统” |
| 追击窗口 | 用户观察到的稳定追击机会 | 待解释的现象，可由多层规则共同造成 | 未确认通用固定计时器 |
| 动作／订单 | Order | 游戏内部执行动作与流程的对象 | 不自动等同于动画或状态 |
| 动作许可 | Availability | 当前上下文中允许尝试哪些动作 | 许可不保证 AI 选择或立即执行 |
| 攻击票据 | Attack Ticket | 群体攻击调度的资格／所有权入口 | 单票据限制不等于全场人数限制 |
| 普通／进阶杂兵 | 当前 Grunt Base／Adv 对照样本 | 主要研究对象 | 不代表所有变体、Boss 与难度 |

## 证据分层

| 类型 | 已能支持 | 不能单独支持 |
|---|---|---|
| 匹配 PDB 的字段／枚举 | 名称、布局、类型与数值 | 谁在何时使用、是否进入实战路径 |
| 有界静态反汇编 | 条件、调用、读写与跳转关系 | 运行时一定走该分支 |
| 本地资产配置 | 保存的数值、引用和图连接 | 缺省值、父级覆盖及最终效果 |
| 用户实测 | 对应场景确实值得解释 | 内部因果或全敌人通用规则 |
| 自动文档检查 | 链接目标、文件和哈希是否完整 | 游戏机制与手感正确 |

## 适用范围与维护方式

| 项目 | 约定 |
|---|---|
| 构建 | 本机 Epic 安装的师父及匹配 PDB；不同版本可能不同 |
| 方法 | 本阶段静态分析；不修改游戏、存档或 LIAN 项目 |
| 写作 | 按主题扩充多篇文档，优先用对照表、规则表和进度表 |
| 完整性 | 机制解释尽量完整；适用条件、例子和未知问题一起保留 |
| 实现深度 | 保留必要数据入口和执行顺序；详细地址、偏移和大段取证留在外部底稿 |
| 双向链接 | 同主题机制篇与实现篇互链，首页统一索引 |
| 计数解释 | 不直接把状态命中计数或 AI 记忆阈值翻译成实战拳数 |
| 数值解释 | 配置值与最终实战效果分开标注 |
| 用户已有内容 | 按输入维护玩家招式衔接图并关联伤害；玩家受击仅在共享逻辑直接相关时顺带研究 |
