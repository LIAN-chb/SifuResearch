## 画面内叠加的配置说明（文档未写、视频里出现）

1. **目标选择四规则**（12s 面板）：
   1. 范围筛选——在搜索范围内收集敌人；与攻击真实命中范围分开配置。
   2. 方向过滤——用玩家朝向与候选方位点积比较；水平距离和夹角用于技能目标筛选。
   3. 目标优先——合法战斗锁定目标优先；否则按已有方最近目标规则选择。
   4. 朝向修正——在 `AN_AttackSnap` 时刻修正攻击朝向，插值/翻转方式以蓝图为准。
2. **连击窗口表**（16s 面板）：`ComboWindow` 打开标签（`Combo_Begin` 起算）；窗口内收到 `Light/Heavy` → `HandleAttackInput` 写入 `BufferedAttackInput`（只记录，不立即造成下一段伤害）；到达派生结算点 → `ComboResolve` 按当前节点和缓存输入选下一节点；处于后摇取消窗口 → 历史攻击输入直接起手 L1/M1，重新起手与继续原段不是同一分支。
3. **退出破定**（52s 面板）：`ExitPoiseBroken` 统一 Timer，清所有状态，移除 GE Handle 并恢复；AI 联动：`isPoiseBroken` 作为高优先级等待分支，暂停移动和攻击，结束后恢复正常决策。
4. **处决**（60–62s 面板）：`GA_Execution` + `ST_ExecutionData` / `PDA_ExecutionData` / `DA_ExecutionData`；检测角色周围所有可处决的敌人，不用刀刃 HitBox 探查。
5. **技力**（34s 面板）：技力每提升一级，最多减少两段前置；消耗所有技力放终结技；终结技关卡序列单独配置。
6. **AI**（82s）：行为树为主 + C++ 随机选择节点；无满足条件技能 → 追击或左右后巡逻。

## 画面里能直接观察到的“效果”

- 全白盒灰模，无美术资源；动作取自网络资源，属于机制验证型 demo。
- HUD：左上横向血条；右侧竖向技力条（Lv.1–3，数值 /300，如 247/300、167/300、30/300）；左下角技能图标（瞬闪、蓄力穿刺、终结斩）；底部一条短蓝条（架势/耐力类）。
- 完美闪避：白色拖影 + 刀光 + 时间膨胀慢动作，期间全程无敌。
- 处决：镜头贴近、位置不同动画不同；处决后敌人定力回满。
- 破定：敌人头顶定力条（黄条）耗尽后进入约 5s 窗口，窗口内受击不重置；5s 后自动回满。
- 敌人技能：旋转持续攻击期间自动追踪；冲撞未命中则到最大距离下砸；三连挥锤；普通三连击。
- 受击表现：伤害/击退/顿帧/打断在动画蒙太奇中统一配置，命中瞬间有火花与轻微顿帧。

## 结论

- 可借鉴：目标选择四规则、连击输入缓存与取消窗口的分支语义、退出破定的统一 Timer 与 AI 联动、处决的“周围扫描而非刀刃 HitBox”、公共 CD 抑制 AI 连放。
- 不可照搬：闪避核心 vs《师父》招架核心；定力数值条 vs《师父》结构条；单敌 AI 无群斗票据；白盒无数值帧数据。
