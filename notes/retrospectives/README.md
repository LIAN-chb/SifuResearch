# 方法复盘

记录实际尝试后的有效步骤、失败边界和成本；决策理由在 [ADR](../../adr/README.md)，执行历史在 [交接](../handoffs/README.md)，本目录只提炼有依据的方法经验。

| 复盘 | 性质 | 可复用要点 | 边界 |
|---|---|---|---|
| [0001-分类后定向重试](0001-分类后定向重试.md) | 历史案例补录 | 按失败层级、相关性与输入变化决定重试 | 当前项目历史报告；本批未重跑，跨引擎未验证 |
| [0002-以本地化和UI引用核招式名](0002-以本地化和UI引用核招式名.md) | 当批复盘 | 精确文本键、源hash及技能UI的名称/说明/输入联合核名 | 本机LocRes v3；不推实战可用性 |

使用 [TEMPLATE.md](TEMPLATE.md)。完成有代表性的尝试、方法失败／反复重试或本批改变取证方法时主动复盘；微小重复执行只引用已有复盘，不生成空文档。没有计时、磁盘或人力数据就写未记录，不估造效率提升。

复盘至少关联问题、实际证据、有效／无效步骤、失败与重试条件、成本及适用假设。补录标明未复验边界。新案例可先追加原记录；条件发生实质变化再独立编号。样本仍局限单项目时保持“可复用候选”。
