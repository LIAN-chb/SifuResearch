## 票据字段读法与机制入口

字段如何驱动建票、申请与指派见[[01机制/敌人AI/攻击票据调度闭环]]；对应的执行逻辑见[[02实现/攻击票据调度闭环]]。

| 字段 | 作用与边界 |
|---|---|
| 常可用 | 为真时只建 1 张，且是主动申请唯一可发的票 |
| 数量 | 建票张数，不是同时出手人数 |
| 角色／角色掩码 | 保存值 4/6/12/14/15 与角色枚举位一致是数值推断，消费代码未找到 |
| 冷却四槽 | 本批未映射到三档难度标签 |
| 按难度计数 | 消费者未定位 |
| 同步开火偏移与容差 | 影响同名票据的开启时机 |
| 重复标志与范围 | 评估指派后重复次数取区间随机 |
| 最小距离 | 影响“已有候选者正在攻击”情境下的取消筛选 |
| 对 Joker 行为 | 0/1/2 三档，决定申请时是否检查情境 |
| 释放后不可用／不用于连招／移动到超时／后备票据 | 仅保存字段，未接通逻辑 |

保存值不等于最终行为；详细证据见 `notes/20261102-攻击票据调度.md`。
