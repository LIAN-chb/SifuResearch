# ADR-0001：由 agent 主动记录用户决策

- 状态：已接受。
- 决策日期／记录日期：2026-10-29／2026-10-29。
- 决策者与来源：用户，本对话当前消息：“添加一个adr目录，每次我做决策都agent主动填写”。同条消息要求沉淀经验用于未来更高效解包和理解其他项目。
- 适用范围与主题：可复用候选；决策管理与研究方法沉淀。目前只在 SifuResearch 建立，跨项目效果尚未验证。

## 背景、决定与理由

研究跨多个对话持续进行，仅保存结果和进度不易恢复当时的取舍。用户决定建立根目录 `adr/`，由 agent 主动记录明确的用户决定，积累未来项目可参考的方法。识别到决定后直接记录，无需用户每次提醒。

agent 对执行方式的细化：同一决定的澄清合并，提议与已接受区分，理由未说明时不猜测；变化通过修订或后继决定保留历史。未见用户对其他决策记录工具作过比较，不补造否决理由。

## 影响与执行位置

[记录约定与索引](README.md)规定触发条件、编号、来源、状态和复用范围；[根规则](../AGENTS.md)要求主动记录，[交接模板](../notes/handoffs/TEMPLATE.md)关联本批决定。代价是持续维护索引与决定的执行位置；通过链接复用底稿，不复制原始证据。

本批实施见 [20261029-决策记录-01](../notes/handoffs/20261029-决策记录-01.md)。本次文档落盘与链接核查不证明未来 agent 必然遵守，也不证明决策方法能直接迁移到任意游戏。

## 复用条件与重新评估

适用于需要跨批次保留选择理由、存在稳定文件存储的研究。迁移到新项目时先检查其工作边界、记录方式和权限，将方法与具体引擎／路径分开。若出现大量重复条目、遗漏决定、来源无法追溯或成本高于收益，调整记录粒度和索引。

历史关系：无。
