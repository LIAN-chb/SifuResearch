# 胜负点决策轴 · 一场战斗到底争什么

> **B-范式层：这里才是"其他方案的思考"。** 同一处冲突，列出所有合理取法与权衡；Sifu 只是轴上的一个坐标。
>
> 对应 A 层节点：[[../A-设计树/01起点与最小可玩]]（M0 起点）。

## ① 通用冲突（主题无关）

任何近战战斗系统，一落笔就必须回答：**双方在争什么？** 若答案默认是"把对方血条打空"，那战斗会退化成**数值换血**——谁数值高谁赢，招式只是皮。这是所有近战系统都会撞上的第一道坎，跟你是功夫、拳击还是剑斗无关。

## ② 决策轴＋权衡

| 取法 | 怎么走 | 得失 |
|---|---|---|
| R1 只争血条 | 唯一胜负量是 HP，打到 0 结束 | 最直白；退化成换血，没有"过程感" |
| R2 血条＋资源条 | 立第二根条（架势/耐力/破绽/体力），资源破→放大伤害或开终结窗口 | 有拉锯、有"破防→终结"节奏；多一套要调的数值 |
| R3 血条＋位置/环境 | 胜负点含位置、靠墙、地形、投技 | 有空间策略；强依赖关卡与相机 |
| R4 血条＋时限/评分 | 战斗含时间压力或评级 | 适合短局/竞技；长战易疲劳 |

> 轴的判断：**你想让玩家"读"的是对手的什么？** 读血条=比数值；读资源条=读破绽；读位置=读站位。选哪根，决定整个战斗的语言。

### 二级轴：一旦选了 R2，"第二资源条"自身还有四问

选了"资源条"只是开头，这条资源怎么运作还要再定四问——每问都是一根可转移的轴：

| 二级轴 | 取法 | Sifu 取点（样例） |
|---|---|---|
| 削条规则 | 每击固定／按攻击类型区分／连段递增 | 按攻击类型+连段 |
| 破条回报 | 只加伤害／开处决窗口／直接终结 | 处决（Take Down）+ 连击 |
| 两条的关系 | 互相独立／破条放大伤害／伤害削条 | 破条后"受击更重" |
| 条能否恢复 | 永不恢复／脱战回复／按时间回 | 可恢复，速度决定压制能否持续 |

## ③ Sifu 取点（红色样例）

> **取点 = R2（血条＋资源条），资源条 = 结构（Structure）。**

- **为什么**：Sifu 的起点是"中国功夫"，而功夫的胜负点不是血条，是"破坏对手的结构"——Layani 原话："功夫的基本策略是打击对手的结构，使他失去攻防能力，且让他受的每一击更重，从而快速终结战斗。"
- 结构条怎么用：敌人头顶白条，每次受击削减；白条空=破架势→处决（Take Down）+ 连击。
- 很早就定：Caselli 原话——"我们把 Structure 做成战斗系统的核心，而且很早就实现了。"
- 机制证据：[[../../05受击状态与节奏]] 的状态记录 / 结构相关配置。

## 转移验证（轴可复用、点不可）

| | 拳击 | 剑斗 | Sifu |
|---|---|---|---|
| 争什么 | 体能/击倒 | 距离/破绽 | 结构 |
| 轴取点 | R2 资源=体力 | R2 资源=破绽 | R2 资源=结构 |

## 适用边界

- 只做 R1 也能成立（如极简格斗/手机休闲），前提是接受"比数值"。
- R2 的代价是多一层数值与状态，且必须处理"资源恢复"否则会单向碾压。
- R3 强绑关卡与相机，不适合纯竞技场。
- 若主题是"功夫/兵器/破绽类"，R2 几乎是必选——因为胜负点本身就在资源而非血量。
